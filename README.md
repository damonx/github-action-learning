# GitHub Action Learning 🚀

A hands-on repository dedicated to learning, testing, and demonstrating **GitHub Actions** CI/CD workflows using a lightweight [Vite](https://vitejs.dev/) web application setup.

---

## 📌 Features

- **Automated Workflows**: Continuous Integration (CI) setups for building and testing.
- **Vite Web App**: Minimal frontend setup using Vite to demonstrate real-world build and deployment pipelines.
- **GitHub Pages / Deployment**: Configured workflows to automatically publish build artifacts.
